# Global Health Insights: An End-to-End Analysis of Global Health Statistics

## Overview
This project analyzes the Global Health Statistics dataset (Kaggle) to understand how disease burden varies by country, age group, and gender, and how healthcare resources and economic factors relate to health outcomes.

## Dataset
Source: https://www.kaggle.com/datasets/malaiarasugraj/global-health-statistics

## Tools
- Python (Spyder, pandas): cleaning and exploratory analysis
- SQL Server (SSMS): data storage and analytical queries
- Power BI: interactive dashboard
- Tableau Public: complementary visual analysis

## Project Workflow
1. Data understanding and cleaning
2. Exploratory data analysis
3. SQL analysis
4. Power BI dashboard
5. Tableau visual analysis
6. Documentation and final presentation
